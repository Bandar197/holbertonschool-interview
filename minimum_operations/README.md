# Minimum Operations

This project calculates the minimum number of operations
needed to produce exactly n H characters.

## Allowed Operations

- Copy All
- Paste

## Function

minOperations(n)

## Examples

- n = 4: 4 operations
- n = 9: 6 operations
- n = 12: 7 operations

## Requirements

- Python 3.4.3
- PEP 8
- Executable Python file
